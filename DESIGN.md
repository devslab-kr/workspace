# Workspace brand

This is an extension of the existing DevsLab OSS Q-line family, not a replacement identity.

## Mark

Retain the 32-unit canvas and the rounded 16-unit planes at (5,5) and (11,11), radius 2. The product route stays inside coordinates 13..25, with at most three primitives, rounded 2.4-unit strokes. Workspace adds a raised left tab followed by a continuous panel rail; the Q frame itself represents retained screen layers.

## Color

The user chose dark blue / light blue. Use `#1D4ED8` on light surfaces and `#93C5FD` on dark `#09090B`. Monochrome uses `#18181B`; reversed uses white. These are product brand assets, not forced changes to the consumer application's `--ws-*` theme.

## Typography and surfaces

Use the product name `Workspace` and the standard `Open source by DevsLab` endorsement. The public README header combines the mark, product name and one concise description. No framework logo belongs inside the mark. Preserve existing UI behavior and app-controlled styling.

## Registry boundary

Workspace is canonical entry O13 in oss-brand v0.4.0. Record the canonical release and source checksums in the vendored manifest. Existing project IDs and assets remain immutable.
