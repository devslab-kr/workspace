# Workspace

<!-- impeccable:product-schema 1 -->

## Platform

Web library with a framework-independent TypeScript core and Solid, React, Vue and Svelte adapters.

## Purpose

Developers register existing business screens and connect menus to open them. Workspace creates tabs, retains visited screens and provides the open-screen switcher. Apps own forms, data, authorization, router integration and subscriptions.
