# Workspace brand

![Workspace](assets/brand/readme-header.png)

Workspace is **O13** in the canonical [DevsLab OSS brand registry](https://github.com/devslab-kr/oss-brand/releases/tag/v0.4.0). The shared Q frame contains a retained-screen and selected-tab route, using stroke 2.4 and two internal primitives. The product colors do not override an application's Workspace CSS tokens.

| Surface | Accent | Background |
| --- | --- | --- |
| Light | `#1D4ED8` | `#FFFFFF` |
| Dark | `#93C5FD` | `#09090B` |
| Monochrome | `#18181B` | `#FFFFFF` |
| Reversed | `#FFFFFF` | `#09090B` |

Use [glyph-color.svg](assets/brand/glyph-color.svg) for light surfaces and [glyph-dark.svg](assets/brand/glyph-dark.svg) for dark surfaces. Identifying marks use `alt="Workspace"`; decorative marks use empty alt text. Preserve the Q geometry, route and approved colors. The canonical assets include outlined wordmarks, favicon, PWA icons, README header and OG image.

The [asset manifest](assets/brand/oss-brand.json) records O13, the canonical release and source checksums. Brand assets are imported from the registry rather than independently redrawn. See [the import instructions](../tools/brand/README.md) to refresh and check the vendored assets.

Download the [official Workspace asset ZIP](https://github.com/devslab-kr/oss-brand/releases/download/v0.4.0/workspace.zip). The company [brand guide](https://devslab.kr/brand/open-source/) explains the shared OSS family and usage rules.
